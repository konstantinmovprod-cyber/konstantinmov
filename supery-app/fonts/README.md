Положите сюда фирменные шрифты — приложение подхватит их автоматически:

- `SoyuzGrotesk-Bold.woff2` (или `.otf`): заголовки
- `CoolveticaCondensed-Regular.woff2` (или `.otf`): лейблы и номера

Пока файлов нет, используются запасные шрифты: Unbounded и Roboto Condensed.
Helvetica берётся из системы.
