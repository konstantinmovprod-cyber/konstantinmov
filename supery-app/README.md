# суперы: Telegram Mini App (MVP)

Мини-приложение клуба по подписке «суперы» (нейросети). Путь от базы к ai-связкам,
клиентам и росту. Сделано по дизайн-системе MASTER YODA AI v2.0: чёрный фон,
кислотный лайм #C5F438, графит, Soyuz Grotesk в нижнем регистре, пилюли,
круглые бейджи-номера, толстый бар и halftone-точки.

Чистый HTML/CSS/JS без сборки. Работает и в Telegram, и в обычном браузере.

## Экраны и паттерны
Паттерны взяты из проверенных приложений для обучения и подписок (Duolingo, Headspace)
и оформлены в дизайн-системе клуба.

- **онбординг**: приветствие, 4 вопроса (цель, уровень, время в день, суперсила) с прогресс-баром,
  затем персональный план: набор уровней, число уроков, срок в неделях. Есть вход по коду доступа.
- **главная**: серия дней 🔥 и XP, кольцо «цель дня», следующий урок из личного плана,
  дни недели, формула клуба, лента, мудрость мастера.
- **путь**: схема 0–10 (лайм/фиолет/циан) с метками «в плане», «твоя сила» и замками на платных уровнях.
- **урок** (шторка снизу): суть, задание, «задание выполнено · +10 xp», вопрос мастеру,
  опционально видео. Закрывается свайпом вниз.
- **пейволл**: польза подписки, выбор тарифа «месяц / год» со скидкой, заявка мастеру,
  ввод кода доступа после оплаты.
- **клуб**: связка месяца, live-разборы, кейсы, обновления.
- **профиль**: серия, XP, % пути, 7 достижений, суперсила, «пересобрать мой путь».

## Контент
Всё редактируется в `config.js`: вопросы онбординга, уровни, **тексты и задания уроков** (`lessons`,
можно добавить `video`), суперсилы, достижения, лента, тарифы, бесплатные уровни (`freeLevels`),
коды доступа (`accessCodes`), хендл, Telegram для заявок и `leadWebhook` (необязательно, туда уходит POST JSON с заявкой
и `initData` Telegram).

Прогресс хранится в `localStorage` на устройстве пользователя.

**Важно:** коды доступа в MVP проверяются в браузере и видны в `config.js`. Это не защита, а
заглушка для теста. Для продакшена нужна проверка оплаты и доступа на сервере (бот + база).

Фирменные шрифты кладутся в `fonts/`, подробности в `fonts/README.md`.

Deep links: `?startapp=level-5` открывает уровень, `?startapp=club` открывает клуб, `?startapp=paywall` открывает тарифы.

## Запуск
```bash
cd supery-app && python3 -m http.server 8080   # http://localhost:8080
```

## Публикация
1. GitHub → Settings → Pages → Source: **GitHub Actions**. Workflow `.github/workflows/pages.yml`
   публикует `supery-app/` при пуше в `main`.
2. В @BotFather выполните `/newapp` (или Menu Button у бота) и вставьте URL страницы.
