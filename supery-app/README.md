# суперы: Telegram Mini App (MVP)

Мини-приложение клуба по подписке «суперы» (нейросети). Путь от базы к ai-связкам,
клиентам и росту. Сделано по дизайн-системе MASTER YODA AI v2.0: чёрный фон,
кислотный лайм #C5F438, графит, Soyuz Grotesk в нижнем регистре, пилюли,
круглые бейджи-номера, толстый бар и halftone-точки.

Чистый HTML/CSS/JS без сборки. Работает и в Telegram, и в обычном браузере.

## Экраны
- **главная**: «суперы», блок «продолжить путь» (следующий уровень и общий прогресс),
  формула клуба (выбери суперсилу → сделай кейс → найди клиента → расти в клубе),
  связка месяца и мудрость мастера.
- **путь**: схема 0–10 (ветки лайм/фиолет/циан, как на исходной схеме) с темами-пилюлями.
  Уровень открывается кнопкой: в нём список уроков с отметкой «пройдено»
  и переходы к соседним уровням.
- **выбор суперсилы** (уровень 2): визуал / контент / web / автоматизация / агенты.
  Выбранная сила подсвечивается на схеме.
- **клуб**: лента уровня 10 (связка месяца, live-разборы, кейсы, обновления) и подписка.
  Кнопка «вступить» отправляет заявку мастеру в Telegram.
- **профиль**: пройденные уровни, уроки, процент пути, суперсила и контакты.

## Контент
Всё редактируется в `config.js`: уровни и темы, суперсилы, лента, цена и состав подписки,
хендл, Telegram для заявок и `leadWebhook` (необязательно, туда уходит POST JSON с заявкой
и `initData` Telegram).

Прогресс хранится в `localStorage` на устройстве пользователя.

Фирменные шрифты кладутся в `fonts/`, подробности в `fonts/README.md`.

Deep links: `?startapp=level-5` открывает уровень, `?startapp=club` открывает клуб.

## Запуск
```bash
cd supery-app && python3 -m http.server 8080   # http://localhost:8080
```

## Публикация
1. GitHub → Settings → Pages → Source: **GitHub Actions**. Workflow `.github/workflows/pages.yml`
   публикует `supery-app/` при пуше в `main`.
2. В @BotFather выполните `/newapp` (или Menu Button у бота) и вставьте URL страницы.
