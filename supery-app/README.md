# СУПЕРЫ — Telegram Mini App (MVP)

Мини-приложение клуба «СУПЕРЫ» в фирменном стиле Konstantin Mov AI Studio:
чёрный + золото, Montserrat / Playfair Display, стекло, острые углы.

Чистый HTML/CSS/JS — без сборки. Работает и внутри Telegram, и в обычном браузере.

## Экраны
- **Главная**: hero, цифры клуба, ближайшее событие, преимущества, «О клубе».
- **События**: фильтр по категориям, карточка события, запись/отмена, лист ожидания,
  закрытые события только для резидентов, «Задать вопрос» менеджеру.
- **Клуб**: каталог участников с поиском.
- **Вступить**: тарифы и заявка → уходит менеджеру в Telegram (или на вебхук).
- **Профиль**: членская карта (имя и аватар из Telegram), мои события, контакты.

Интеграция с Telegram: `ready/expand`, цвета шапки, системная кнопка «Назад»,
вибрация (haptics), автозаполнение имени и @username, deep link `?startapp=ev-1`.

## Как поменять контент
Всё редактируется в `config.js`: название, тексты, события, участники, тарифы,
Telegram менеджера, почта, `leadWebhook` (необязательно).

Записи на события и заявка в MVP хранятся в `localStorage` пользователя.
Чтобы заявки приходили вам централизованно, укажите `leadWebhook`
(n8n, Make, Google Apps Script или свой сервер): туда уходит POST JSON с данными
и `initData` Telegram (подпись проверяйте на сервере).

## Локальный запуск
```bash
cd supery-app
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Публикация и подключение к боту
1. Включите GitHub Pages: Settings → Pages → Source: **GitHub Actions**.
   Workflow `.github/workflows/pages.yml` публикует папку `supery-app` при пуше в `main`.
   Получится адрес вида `https://<user>.github.io/<repo>/`.
2. В @BotFather: `/newbot` (если бота ещё нет) → `/newapp` → выберите бота →
   укажите этот URL. Либо `/mybots` → Bot Settings → Menu Button → тот же URL.
3. Готово: приложение открывается из кнопки меню бота или по ссылке `t.me/<бот>/<app>`.
